# Kaggle_yty

个人 Kaggle 与竞赛项目的集合仓库。原先分散在多个独立仓库中的项目，现统一收纳为本仓库的子目录，各自保留原始的提交历史。

## 子项目

### 1. Kaggle_Digit_Recognizer

Kaggle Digit Recognizer 手写数字识别竞赛。包含数据检查、样本可视化、SVM 基线、CNN 训练与提交文件生成的完整流程。

### 2. Kaggle_House_Price

Kaggle House Price 房价预测竞赛。包含目标变量分析、缺失值处理、数值/类别特征分析、异常值处理、基线模型与改进的集成模型。

### 3. Kaggle_Spaceship_Titanic

Kaggle Spaceship Titanic 乘客转运预测竞赛。包含数据探查、EDA 可视化、基线模型与 CatBoost 交叉验证。

### 4. Card_Game_Agent_AI_Battle

为 Kaggle 上的 PTCG AI Battle Challenge（宝可梦集换式卡牌 AI 对战）开发的参赛 Agent，属于非官方的学习与作品集项目。
